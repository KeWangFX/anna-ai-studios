# Anna AI Studios mail backend

Maintained source for the owner-authorised Google Apps Script Web App version 3. Both homepage forms submit to `https://anna-ai-studios.pages.dev/api/contact`; the Cloudflare Pages Worker relays requests to the fixed Apps Script endpoint at `/exec?transport=relay-v1` and renders the result on the studio domain. Visitors do not need to connect directly to Google domains. These files are excluded from the static site's explicit public-file manifest.

- `Code.gs`: native URL-encoded POST handler, strict field validation, Turnstile server verification, quota/rate limits, idempotent send states, and bilingual result/receipt copy.
- `appsscript.json`: V8/UTC manifest with only `script.send_mail` and `script.external_request` OAuth scopes.
- `test_backend.cjs`: deterministic offline tests; its secret/token literals are deliberately invalid fixtures. No test contacts a provider or sends mail.

Operational properties are set only in the owner Apps Script project. `TURNSTILE_SECRET` must never enter this repository, generated HTML, logs or public build. `ANNA_ENABLED=true` permits delivery; keep it false while verifying a new deployment. `deploymentPreflight()` reports remaining recipient quota, enablement and secret presence without returning the secret. The deployed backend is enabled. Rerun preflight before each controlled rollout because quota and configuration can change; a historical quota reading does not establish the current remaining allowance.

Google consumer MailApp currently permits 100 recipients per day. This backend is stricter: 20 enquiries per rolling 24 hours, 5 per rolling hour, 2 per submitting address per rolling day; each enquiry sends a fixed owner notification and a fixed visitor receipt, retaining a two-recipient reserve. Verification work is bounded separately to 200 attempts per rolling day and 10 per minute. Those shared budgets can be exhausted by invalid traffic; no DDoS-resistance claim is made. Limits stop execution rather than use a paid fallback. Official quotas: https://developers.google.com/apps-script/guides/services/quotas

`privacy_consent` must be exactly `Agreed`. Frontend HTML-to-backend parser tests live in `scripts/test_contact_contract.cjs`; these catch enum/field drift across languages. Run `npm run validate` after changing either side. When Code.gs changes, update the existing Web App deployment version as well as this source; saving source alone does not update a versioned `/exec` deployment.

MailApp's return means acceptance by the sending API, not final inbox delivery. Production validation on 25 October 2026 at 10:32 GMT confirmed all four notifications and localized receipts for Chinese main-site and English GitHub-mirror enquiries through the version 3 relay, with matching Lead IDs and original text preserved. This evidence covers the owner's Gmail address and its controlled plus-address alias only; it does not establish cross-provider delivery, mainland-China access or mobile WeChat availability. Future delivery changes still require marked enquiries and actual inbox checks. Retain direct-contact fallbacks. No backend source, tests, manifest, operational properties or credentials belong in `cloudflare-release/`.
